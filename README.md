# Student Management System

## Technologies 
- React.js
- Node.js
- Express.js
- PostgreSQL
- Bootstrap


## Features
- Add Student
- View Students
- View Student by ID
- Update Student
- Delete Student


## Setup Instructions

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start

## Database
Run database.sql in PostgreSQL.

## API Testing
Import Postman collection JSON file into Postman.
